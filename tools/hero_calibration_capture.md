# 英雄外参采集使用说明（2026-10-12）

在机器人桌面终端运行：

    cd /home/rcs/rm_project/SHtech_auto_aim
    bash tools/start_hero_calibration.sh

启动脚本使用 launch_calibration.cfg，自动为该进程设置 DRY_RUN=1 和 TRACK_ONLY=1，只显示 sensor_submodule 窗口，关闭自动采样。它仍复用完整主程序；检测、预测和规划模块仍会运行，XUC UART 发送由 DRY_RUN 阻断。不要将其描述为独立的只接收采集程序，也不能据此保证下位机自身的供弹或摩擦轮行为。

脚本每次创建新数据目录并打印绝对路径，也可传入一个尚不存在的目录。它拒绝已有目录，不覆盖旧数据。只做静态检查、不启动程序：bash tools/start_hero_calibration.sh --check。

棋盘为 10×8 方格、20 mm 格长，程序检测 9×7 内角点。底盘和棋盘保持固定，相机和 IMU 的安装不变；只转云台。抬头、低头、左转、右转及其组合都应覆盖，以完整棋盘清晰入镜为范围，不预设未知机械限位。

每次转动后停稳，建议先等待 1–2 秒并观察画面和姿态稳定。点选 sensor_submodule 窗口，确认 Detected: 63 corners 和 RX fresh，然后按 p 或 P。窗口下一帧显示 Saved pair 编号，终端打印保存路径。程序保存未画检测线的原分辨率 PNG，并配对保存 euler_编号.txt：yaw pitch roll，单位度，保留当前 RX 符号。Ctrl+C 在启动终端中退出。

保存要求：完整棋盘可检测；姿态已收到且在图像读取时距回调不超过 250 ms；角度有限；DRY_RUN=1；两个文件都写入成功。该 250 ms 是缓存过期保护，不是曝光与 IMU 同步精度，也不是停稳判断。仍必须停稳后采集，当前没有自动稳定性门控或硬件同步。

先采 3–5 对确认实际图像清晰、姿态更新、配对齐全；再采 20–40 个不同有效姿态，另取 5–10 个验证姿态。保持一个批次内棋盘和底盘不动，不重置 IMU 零位。机械测量原点和轴向仍需明确。

两阶段求解沿用交接中的顺序。本次未修改外参、内参、日常 launch.cfg、求解脚本或网络设置；联合脚本的旧机械长度约束仍需要后续适配。

验证：实机程序编译成功；20 项合成数据/保存检查通过；用部署构建的 Sensor 对象、合成 FFV1 视频及隔离 Xvfb，6 项实际 P 键集成检查通过。测试没有使用真实相机或 UART，真实棋盘现场试采尚未进行。
